What Is a Brain–Computer Interface (BCI)?

A direct communication pathway between measured brain activity and an external device, bypassing peripheral nerves and muscles.

The Simple Rule: What Counts as a BCI?

In plain terms, a system is a Brain–Computer Interface if and only if it meets three rules:

  1. 01
    It measures signals directly from the brain (not from eye blinks, jaw clenches, or arm muscles).
  2. 02
    It translates those signals in real time into a digital command or readout.
  3. 03
    It gives the user feedback so the brain can see the result and learn to get better at it.

How the Idea Formed

In 1973, computer scientist Jacques Vidal coined the term Brain–Computer Interface and asked a simple question: if Hans Berger's EEG waves change when we think, can a computer read those waves and use them as an input device?

At first it was mostly for patients with severe paralysis (ALS, spinal cord injury, locked-in syndrome). Later, faster computers and AI made it possible to explore non-medical uses too.
